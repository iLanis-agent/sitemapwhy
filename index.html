One missing xmlns and the whole sitemap fails schema validation.

<urlset><url><loc>http://example.com/</loc></url></urlset> fails the namespace is missing, so no element is a sitemap element <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"> ... passes

What it does

  • Says whether the file is well-formed XML, then whether it passes the sitemap schema, with the line of each problem.
  • Explains the usual traps: raw & in URLs, missing namespace, lastmod without seconds, wrong tag order, changefreq in the wrong case, priority above 1.
  • Given the sitemap's location, shows which URLs would be dropped for the wrong host, protocol, port or folder, and flags the 50,000 URL and 50MB limits.

How far to trust it

  • Schema verdicts match libxml2 validating against the real sitemap.xsd and siteindex.xsd on 180,000 generated and mutated documents. Folder, host and size rules come from the protocol text and were not compared with a validator. Search engines may be stricter or looser.
